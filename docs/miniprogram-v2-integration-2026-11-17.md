# 小程序新版前端接入记录（2026-11-17）

本次改动位于 `miniprogram/`，原生微信小程序直接接 V2 API。没有发布微信正式版，也没有将线上 API 切换到 V2。三省例行监控继续使用独立数据库。后续已按评审原型重做界面，详见 [原型对齐记录](ui-prototype-alignment-2026-11-17.md)。

## 已接入

- 首页：全国/国家/省份选择；选择省份后可关闭“同时查看国家级文件”；业务主题、文件类型、发布时间筛选、采集时间与来源状态入口。底部为“政策／关注／我的”，招聘入口按收敛计划隐藏。
- 搜索与列表：传递全部筛选条件；关键词可匹配标题、文号、正文和发文机构；编码处理中文及特殊字符；新查询忽略旧请求；失败不跳页、不丢失已显示内容。
- 详情：显示官网来源地区、发布机构、文号、分类、摘要、已收录正文和附件状态。来源地区不等于文件适用范围；缺失发布机构不再默认显示“国家卫生健康委”。原文/附件提供官网链接复制，不声称已经支持微信内跨域下载预览。
- 账号收藏：微信登录、服务端读取/新增/取消收藏；失效 token 最多续登重试一次；并发请求共享登录；写入失败不显示成功。V2 不复用 V1 本地收藏的数字 ID，不自动迁移旧收藏。
- 来源与更新：区分来源登记、采样验证与运行时启停；不把 31 省登记误报为全部省份正在更新或历史全量覆盖。
- V2 暂无全国政策 AI 问答接口，首页不显示旧版问答入口，旧路由在 V2 模式下也给出明确提示。

## 接口地址在哪里配置

统一配置文件：`miniprogram/config/environments.js`。`app.js` 按 `wx.getAccountInfoSync().miniProgram.envVersion` 选择配置；未知环境回到正式版配置。

| 微信版本 | 接口 | 状态 |
| --- | --- | --- |
| develop 开发版 | `http://127.0.0.1:8891/api/v2` | 接 V2，用于开发者工具本机联调 |
| trial 体验版 | 暂未填写 | 接 V2，但明确提示“体验服务尚未配置”，不偷偷回退旧库 |
| release 正式版 | `https://wjwjwjw.top/api/v1` | 继续 V1，待体验验收后再切换 |

体验版上线前，将 `profiles.trial.API_V2_BASE` 填为实际部署、证书有效、微信后台 request 合法域名允许的 HTTPS 地址。开发版手机预览也须将 develop 地址改为手机可访问的 HTTPS 测试地址；手机的 `127.0.0.1` 不是这台 Mac。

没有增加任意地址输入 UI。token 按环境及 API 基础地址隔离，旧版无环境命名空间的 token 不再复用。前端不得放 AppSecret 或管理员 token。

## 用真实采集数据在本机联调

从仓库根目录运行（依赖已有 `.venv`）：

```sh
PYTHONPATH=backend .venv/bin/python scripts/serve_miniprogram_preview.py \
  --snapshot-from .runtime/monitor-trial-20261117/trial.db
```

脚本通过 SQLite backup API 只读复制源库，生成临时快照，仅监听 `127.0.0.1:8891`。快照内来源监控关闭、不启动采集任务、不修改原监控库；退出即清理。附件原件不复制，前端仍可复制官网附件链接。为防止误连真实账号，预览关闭微信登录并清理复制来的会话，账号操作显示“账号同步暂未开放”。需要收藏真机验收时，使用配置了微信 AppID/AppSecret 的独立测试服务。

在微信开发者工具中导入 `miniprogram/`，使用项目已配置的 AppID，编译首页。手动运行上述命令时，关闭终端后需重新运行。2026-11-17 为持续进行 UI 联调，当前预览改由临时 launchd 服务 `com.weijianwei.miniprogram-preview` 运行；先停止它再手动运行，避免端口冲突，具体命令见原型对齐记录。未安装登录自启项。本机快照含广东 28、宁夏 21、北京 245 条文件，均能读取正文；原监控库仍有 3 个启用来源。该数字不是当前线上内容数量。

## 自动验证

```sh
node miniprogram/tests/run.js
```

6 组检查均通过：

1. API 登录失效、并发续登、环境 token 隔离、V1 回退、体验地址缺失保护。
2. 页面 + 真实 FastAPI 契约：地区、含/不含国家、正文搜索、详情/附件、账号收藏读写、来源状态与 404。仅微信服务端换码模拟；FastAPI 路由、认证、数据库写入均实际执行于隔离临时库。
3. 首页刷新失败、翻页失败、采集时间、旧请求覆盖保护。
4. 页面跳转筛选参数、搜索竞态、未提交搜索词不影响翻页、清空查询、收藏失败不伪成功、空正文与错误恢复。
5. 包含国家参数、省份、类型和发布日期等筛选条件在列表与搜索间的传递。
6. 按小程序 JavaScript 模块规则加载 App 和全部页面，防止 Node 支持而微信不支持的 JSON require 再次导致白屏。

后端 `test_policy_v2_api.py` 现为 8 项通过，包含新增日期边界、发文机构搜索和取消关注权限验证。本机 HTTP 真实采集快照冒烟检查通过。没有修改采集逻辑，本轮没有重复运行全部采集测试。

将地区名称表改为 `config/regions.js`，使用 `module.exports`，更新 API、筛选和来源页三个引用。新增 `module-loading.test.js`，按小程序 JavaScript 模块注册规则加载 App 和全部页面：修复前因 `regions.json.js` 不存在失败，修复后通过。现有自动验证扩展为 6 组，全部通过。

微信开发者工具重新编译后，首页控件及政策卡片恢复。本机真实模拟器补充验证通过：页面渲染、省份与国家级筛选方法、筛选范围继承搜索、文件卡片跳转方法、详情、正文和来源覆盖页；快照共 294 条文件、33 个地区选项（全国、国家及 31 省），来源登记 64 个栏目。本次自动化通过官方 SDK 调用页面交互方法并检查视图；原生 picker 的手动选取手势仍需人工验收。
